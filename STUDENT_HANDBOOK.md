# Claude Code Mastery — Student Handbook

**Course:** Claude Code Mastery (CCM) v1.0.0
**Your Goal:** 95% mastery (FORGED level)

Welcome. This handbook explains how the course works, how you'll be assessed, and how to get the most out of every session.

## How the Course Works

### Structure

- **27 modules** organized into **5 tiers** (Foundations → Intermediate → Advanced → Expert → Mastery)
- Each module covers a specific feature area of Claude Code
- Modules have **prerequisites** — you unlock later modules by completing earlier ones
- See `MODULE_DEPENDENCIES.md` for the full prerequisite map

### Delivery Format

Each module is delivered as:

1. **Interactive lesson** — Your instructor (JayBrain) teaches the material with demonstrations, examples, and vivid explanations
2. **Hands-on exercises** — You practice the features yourself in your sandbox environment
3. **Quiz questions** — Concepts are added to your study queue and tested via spaced repetition
4. **Reference doc** — A written reference is saved to Google Docs for future review

### Sessions

- Each session covers 1-3 modules depending on complexity
- Sessions can be any length — stop when you need to
- Progress is saved automatically across sessions
- You can pick up exactly where you left off

## How Quizzing Works

### The Quiz Protocol

Quizzes are integrated throughout the course, not just at the end of modules. As you learn new concepts, they enter your study queue and get tested via spaced repetition.

**Question format:**
- Multiple choice: A, B, C, D
- Plus two special options:
  - **E** = "I don't know" (honest — no penalty for admitting gaps)
  - **F** = "Question previous question" (pause to discuss the last question)

**How to answer:**
- Respond with **one letter + one number** in a single message
- The letter is your answer (A-D), the number is your confidence (1-5)
- Example: `B4` = "I think it's B, and I'm fairly confident"
- Example: `C2` = "I'll go with C, but I'm not very sure"

**Confidence scale:**
| Score | Meaning |
|-------|---------|
| 1 | Total guess |
| 2 | Slight lean |
| 3 | Think I know |
| 4 | Fairly sure |
| 5 | Absolutely certain |

### Special Commands During Quizzes

| Command | What It Does |
|---------|-------------|
| **E** (as answer) | "I don't know" — skip, concept marked for review |
| **F** (as answer) | Pin current question, discuss previous question, then resume |
| **SIDEQUEST** | Pause the quiz to ask any question, then resume exactly where you left off |
| **TIMEOUT** | Pause for meta/process discussion (course feedback, settings, etc.), then resume |

### After Every Answer

Your instructor will:
1. Tell you if you were right or wrong
2. Explain **why** the correct answer is correct (with a memorable analogy)
3. Explain **why each wrong option** is wrong (specific, not vague)
4. If you were wrong: explain the misconception and what you confused

### Stats and Progress

- **After every question:** Quick stats (concept mastery, session accuracy, all-time accuracy)
- **Every 10 questions:** Full dashboard (domain breakdown, weak areas, pass probability)
- **Anytime:** Ask "how am I doing?" for a readiness check

## Mastery Levels

Your progress is measured on a mastery scale:

| Level | Range | What It Means |
|-------|-------|---------------|
| Spark | 0-20% | Just encountered the concept |
| Ember | 20-40% | Recognize it, can't explain it yet |
| Flame | 40-60% | Can explain and use in simple cases |
| Blaze | 60-80% | Can apply in complex scenarios |
| Inferno | 80-95% | Consistent performance, rare mistakes |
| **FORGED** | **95%+** | **Complete mastery — you've passed** |

---

## How Scoring Works (The Short Version)

Your mastery score goes up when you answer correctly and down when you answer incorrectly. The amount it changes depends on your confidence:

- **Right and confident** = Big boost (+0.20)
- **Right but unsure** = Moderate boost (+0.10)
- **Wrong and confident** = Bigger penalty (-0.15) — this flags a misconception
- **Wrong and unsure** = Small penalty (-0.05) — expected gap, no shame

**Key takeaway:** Don't inflate your confidence. Being wrong AND confident is the worst outcome. It's better to be honest about uncertainty.

## What Gets Logged

Everything is tracked to help you learn more efficiently:

1. **Every quiz answer** — response, confidence, correctness, time
2. **Error patterns** — what kinds of mistakes you make and where
3. **Mastery progression** — per concept, per module, per domain
4. **Key learnings** — important insights saved as memories
5. **Module completion** — updated in your progress doc on Google Drive

You don't need to do anything — logging is fully automatic. Just focus on learning.

## Tips for Success

### Before a Session
- Review the last session's key takeaways (ask JayBrain for a recap)
- Check your weak areas (ask for a readiness report)
- Make sure your sandbox environment is ready

### During a Session
- Ask questions aggressively — there are no dumb questions
- Use SIDEQUEST to explore tangents without losing your place
- Try things yourself before being told the answer
- When something clicks, say so — it helps calibrate the teaching

### During Quizzes
- Be honest with confidence scores — don't guess high
- If you don't know, pick E — it's better than a random guess
- If a question is confusing, pick F to discuss it
- Read ALL options before answering — wrong options often teach as much as right ones

### Between Sessions
- Use Claude Code! The best learning is doing.
- Try the features you learned in real projects
- If you discover something new, mention it next session
